# 세이코어 근태관리 사용 가이드

출퇴근 기록과 휴가·시차 엑셀 파일을 넣으면 근태 요약, 지각·미등록 현황, 시말서 대상자를 자동으로 정리해 주는 프로그램입니다.

## ⬇️ 다운로드

### 👉 [최신 버전 다운로드 페이지](https://github.com/countrygirl-v/check-attendance-releases/releases/latest)

- 이 페이지는 항상 최신 버전으로 연결됩니다. **즐겨찾기**해 두세요.
- GitHub 계정이나 로그인은 필요 없습니다.

| 언제 | 할 일 | 걸리는 시간 |
|---|---|---|
| 처음 한 번 | 설치 파일 받기 → 설치 | 약 2분 |
| 새 버전이 나왔을 때 | 알림 창에서 다운로드 → 설치 파일 다시 실행 | 약 1분 |
| 평소 | 바탕화면의 **세이코어 근태관리** 아이콘 더블클릭 | - |

---

## 1. 처음 설치하기

관리자 권한이나 Java 설치는 필요 없습니다.

1. 위의 **[최신 버전 다운로드 페이지](https://github.com/countrygirl-v/check-attendance-releases/releases/latest)** 를 엽니다.
2. 페이지 아래쪽 **Assets** 에서 `Saycore-Attendance-Install-버전.exe` 를 눌러 다운로드합니다.
   - `.zip` 파일과 `Source code` 는 받지 않아도 됩니다.
3. 브라우저가 다운로드를 막으면 아래처럼 허용합니다. 사내에서 만든 프로그램이라 나오는 경고입니다.
   - **Edge**: '일반적으로 다운로드되지 않습니다' → 파일 옆 **⋯** → **유지** → **자세히 표시** → **그래도 계속**
   - **Chrome**: '안전하지 않은 파일' → **유지**
4. 다운로드한 파일을 더블클릭합니다.
5. 파란색 **'Windows의 PC 보호'** 창이 뜨면 **추가 정보** → **실행** 을 누릅니다.
6. 설치 화면에서
   1. **바탕 화면에 바로 가기 만들기** 가 체크된 상태로 **설치** 를 누릅니다.
   2. 설치가 끝나면 **세이코어 근태관리 실행** 이 체크된 상태로 **마침** 을 누릅니다.
7. 프로그램이 열리고, 창 제목에 `세이코어 근태관리 v1.1.1` 처럼 버전이 보이면 성공입니다.

다음부터는 **바탕화면의 세이코어 근태관리 아이콘**으로 실행하세요. 바탕화면에 없으면 시작 메뉴에서 `근태` 또는 `세이코어` 로 검색하면 됩니다.

> 예전에 따로 받아서 쓰던 exe 파일은 이제 필요 없으니 지워도 됩니다. 설치가 끝난 뒤 다운로드한 설치 파일도 지워도 됩니다.

---

## 2. 새 버전이 나왔을 때

새 버전이 나오면 프로그램을 켤 때 아래 같은 알림 창이 저절로 뜹니다. 따로 확인하러 올 필요는 없습니다.

```
업데이트 안내

새 버전이 나왔습니다.

현재 버전: v1.1.1
최신 버전: v1.2.0

[ 다운로드 페이지 열기 ]   [ 나중에 ]
```

1. **다운로드 페이지 열기** 를 누르면 브라우저에 다운로드 페이지가 열립니다.
2. 프로그램을 **닫습니다.**
3. **1. 처음 설치하기** 의 2~6번을 똑같이 합니다.
   - 기존 버전은 지우지 않아도 새 버전으로 자동으로 바뀝니다.
   - 프로그램이 켜져 있으면 설치 화면에서 닫을지 물어봅니다. **자동으로 닫기** 를 선택하세요.
4. 창 제목의 버전이 바뀌었는지 확인합니다.

**나중에** 를 눌러도 지금 버전은 그대로 쓸 수 있고, 다음에 프로그램을 켤 때 다시 알려줍니다. 단, 담당자가 업데이트를 요청한 경우에는 바로 설치해 주세요.

## 3. 자주 묻는 질문

<details>
<summary><b>알림 창이 한 번도 안 떠요.</b></summary>

인터넷이 연결되지 않았거나 회사 보안으로 막히면 알림이 뜨지 않습니다. 이때는 [다운로드 페이지](https://github.com/countrygirl-v/check-attendance-releases/releases/latest)를 직접 열어서, 페이지 맨 위 버전(예: v1.2.0)과 프로그램 창 제목의 버전을 비교해 주세요.
</details>

<details>
<summary><b>바탕화면 아이콘을 실수로 지웠어요.</b></summary>

시작 메뉴에서 `근태` 로 검색하면 나옵니다. 바탕화면 아이콘을 다시 만들려면 설치 파일을 한 번 더 실행하세요.
</details>

<details>
<summary><b>엑셀 파일이 인터넷에 올라가나요?</b></summary>

아니요. 출입기록과 휴가 파일은 내 PC 안에서만 처리됩니다. 프로그램이 인터넷에 연결하는 것은 새 버전 번호를 확인할 때뿐입니다.
</details>

<details>
<summary><b>프로그램에 문제가 생겼어요.</b></summary>

프로그램 왼쪽 아래 **Log** 버튼 → **다운로드** 를 누르고, 저장된 로그 파일을 개발 담당자에게 보내 주세요. 어떤 파일을 넣었는지, 언제 문제가 생겼는지도 함께 알려 주시면 빨리 해결할 수 있습니다.
</details>

<details>
<summary><b>프로그램을 삭제하려면요?</b></summary>

Windows **설정** → **앱** → **설치된 앱** 에서 `세이코어 근태관리` 를 찾아 **제거** 를 누릅니다.
</details>

<details>
<summary><b>설치하지 않고 쓸 수는 없나요?</b></summary>

다운로드 페이지의 `Saycore-Attendance-버전-windows.zip` 을 받아 압축을 풀고, `SaycoreAttendance` 폴더 안의 `SaycoreAttendance.exe` 를 실행하면 됩니다. 이 경우 exe 파일만 다른 곳으로 옮기면 실행되지 않고, 업데이트할 때도 zip을 다시 받아야 합니다. 특별한 이유가 없으면 설치 파일을 권장합니다.
</details>

---

해결되지 않는 문제는 개발 담당자에게 문의해 주세요.
